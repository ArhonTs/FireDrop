# FireDrop

**Быстрая передача файлов и целых папок по локальной Wi-Fi сети: с компьютера на телефон, с телефона на компьютер и с телефона на телефон.** Без интернета, облака и регистрации.

Документация на английском: [README.en.md](README.en.md)

Исходный код: https://github.com/ArhonTs/FireDrop — лицензия GNU GPL v3.
Интерфейс приложений и веб-страницы: русский и английский. По умолчанию язык берётся из системы, а в настройках можно выбрать его вручную: **«Системный»**, **«Русский»** или **«English»**.

## Возможности

- Файлы и **целые папки** с сохранением структуры каталогов; десятки МБ/с — упирается только в Wi-Fi.
- Подключение по **QR-коду** (адрес + токен) или **шестизначному PIN**-коду с ограничением попыток.
- Поиск устройств в сети по UDP; приём в фоне foreground-сервисом с уведомлением.
- Принятые файлы не перезаписываются: `имя (1).ext`, `имя (2).ext`…
- Работает на телефон ↔ телефон, телефон ↔ компьютер — без облака.

## В выпуске

| Файл | Назначение |
| --- | --- |
| `FireDrop.exe` | Windows 10 (22H2)/11 x64, самодостаточный — ничего устанавливать не нужно |
| `FireDrop-<версия>.apk` | Android 8.0+ (около 300 КБ, без Google Play Services) |
| `SHA256SUMS.txt` | Контрольные суммы |

## Телефон → компьютер

1. Запустите `FireDrop.exe`. Если Windows спросит — разрешите доступ **для частных сетей**.
2. Телефон подключите к той же Wi-Fi сети.
3. Отсканируйте QR-код с экрана компьютера камерой телефона (откроется страница FireDrop) или откройте **«Отправить»** в Android-приложении.
4. Выберите файлы или папку и дождитесь окончания передачи. Файлы попадут в папку сохранения (по умолчанию `C:\Users\<имя>\Downloads\FireDrop`).

Браузерная страница умеет выбирать отдельные файлы и **папку** (настольные Chrome/Edge/Opera; в мобильном Safari папки нет). На телефоне надёжнее приложение: оно умеет выбирать папки на любой поддерживаемой версии Android.

## Телефон → телефон

1. На принимающем телефоне **«Принять»** → **«Включить приём»**, разрешите уведомления.
2. На отправляющем — **«Отправить»** → **«Найти рядом»** и выберите устройство, либо **«QR»** и отсканируйте QR-код принимающего.
3. Введите шестизначный код (при сканировании QR подставится сам), выберите файлы или папку и отправьте.

Принято — в `Download/FireDrop`, структура папок сохраняется. На Android 10+ система не даёт создавать пустые каталоги через MediaStore — они пропускаются, а файлы создают свои папки сами.

## Компьютер → телефон

1. На телефоне включите приём (см. выше).
2. На компьютере нажмите кнопку с самолётиком — откроется панель **«Отправить на телефон»**.
3. Укажите получателя: **«Найти рядом»**, QR-текст (`firedrop://send?…`), либо адрес и код вручную.
4. **«Файлы…»** или **«Папка…»** → **«Отправить»**.

## Требования

- Windows 10 (22H2) или Windows 11, 64-бит (`FireDrop.exe` самодостаточный).
- Android 8.0+ для приложения; Chrome/Edge/Firefox/Safari/Samsung Internet для страницы.
- Устройства в одной Wi-Fi сети, на роутере отключена изоляция клиентов (AP isolation), сеть не гостевая.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| Компьютер не открывается с телефона | Одна и та же Wi-Fi сеть; выбран правильный адрес в окне FireDrop (кнопка рядом с адресом внизу); брандмауэр; VPN выключен; изоляция роутера |
| «Найти рядом» ничего не находит | Приём/сервер реально включены; UDP-порт 47822 разрешён; подсети совпадают; VPN выключен |
| QR не сканируется | 10–30 см, камера в фокусе, яркость экрана, кнопка «Снять кадр для распознавания»; в крайнем случае адрес и код вручную |
| Телефон не принимает файлы | Уведомления разрешены (Android 13+), оптимизация батареи отключена, место есть; Android ≤9 — разрешите доступ к памяти |
| Передача прерывается/медленно | Ближе к роутеру, 5 ГГц, не блокируйте экран, VPN/энергосбережение выключены |

## Настройки

**Windows** (кнопка с ползунками): имя компьютера, папка сохранения, порт (по умолчанию `47820`), язык, автозапуск, сворачивание в трей. Настройки в `%APPDATA%\FireDrop\settings.json`.

**Android**: имя устройства, порт приёма, папка приёма (`Download/FireDrop`, фиксированная), язык.

**Брандмауэр**: правила привязаны к точному пути `FireDrop.exe` — после обновления в новой папке снова нажмите **«Разрешить FireDrop в сети»** в настройках (создаст и TCP 47820, и UDP 47822 для текущего пути и порта). Вручную через PowerShell от администратора:

```powershell
New-NetFirewallRule -DisplayName "FireDrop TCP" -Direction Inbound -Protocol TCP -LocalPort 47820 -Action Allow
New-NetFirewallRule -DisplayName "FireDrop UDP" -Direction Inbound -Protocol UDP -LocalPort 47822 -Action Allow
```

## Скорость

Выбирайте сети 5 ГГц / Wi-Fi 6-7, держите телефон у роутера, отключите VPN и гостевую сеть, не блокируйте экран отправителя (приложение само удерживает его включённым). Ориентир — около **30 МБ/с** в тестовой сети Wi-Fi 5; на гигабитном Wi-Fi может быть выше.

## Безопасность

- Сервер работает только в локальной сети, доступ только по QR-ссылке с токеном или PIN-коду (несколько неверных попыток — временная блокировка).
- Трафик — HTTP внутри Wi-Fi сети; не используйте FireDrop в общедоступных сетях и не покаживайте QR/PIN посторонним.

## Установка на Android

1. Скопируйте APK на телефон и откройте; разрешите установку «из неизвестных источников» для проводника/браузера.
2. Play Protect: **«Подробнее» → «Всё равно установить»** (подписная часть не из магазина).
3. Android 13+: разрешите уведомления; Android ≤9: разрешите доступ к памяти.
4. Телефоны Xiaomi/Huawei/Samsung: «Батарея → Без ограничений» для FireDrop, иначе система прибирает приём.

## Журналы и диагностика

`%APPDATA%\FireDrop\logs\firedrop.log`, незавершённые загрузки `%APPDATA%\FireDrop\partial` (очищаются автоматически). Android: `adb logcat -s FireDrop`.

SmartScreen может предупредить о неподписанном `FireDrop.exe` — **«Подробнее» → «Выполнить в любом случае»**, если скачали из доверенного источника.

## Сборка из исходников

**Windows** (нужен [.NET 10 SDK](https://dotnet.microsoft.com/download)):

```powershell
dotnet publish .\FireDrop\FireDrop.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -o .\dist
```

**Android** (JDK 17, Android SDK Platform 34, Build-Tools 34.0.0; Gradle не нужен):

```powershell
.\Android\build.ps1 -Sdk "C:\Android\sdk" -Jdk "C:\Program Files\Java\jdk-17"
```

Скрипт при первом запуске создаёт ключ подписи `Android\keystore\firedrop.jks` — сохраните его, иначе обновления не поставятся поверх старых. На Linux тот же конвейер (для build-сервера F-Droid): `bash Android/fdroid-build.sh` → `Android/build/FireDrop-unsigned.apk`.

Библиотека zxing 3.5.3 (Apache-2.0) не хранится в репозитории — jar скачивается с Maven Central по SHA-256 при первой сборке.

## Лицензия и F-Droid

Репозиторий — под **GNU GPL v3** (файл `LICENSE`). Единственная сторонняя зависимость — ZXing (Apache-2.0).

F-Droid собирает приложение сам из открытого исходного кода и подписывает своим ключом. Метаданные: `metadata/ru.firedrop.app.yml` (копируется в `metadata/` вашего `fdroiddata` и отправляется merge request в [fdroiddata](https://gitlab.com/fdroid/fdroiddata)). Новые версии подхватываются по тегам `v1.2.4`, `v1.2.5`… Тексты обновлений — в `Android/fastlane/metadata/android/*/changelogs/<versionCode>.txt`.

**Нюанс**: APK из F-Droid подписан их ключом, APK из этого репозитория — вашим `firedrop.jks`; поверх друг друга они не ставятся — при переходе сначала удалите приложение. Пользователям каталога F-Droid достаточно обычных обновлений из него.

## Структура проекта

- `FireDrop/` — исходный код WPF-приложения, встроенный ASP.NET Core-сервер, страница телефона (`FireDrop/Web/`), словари интерфейса (`FireDrop/L10n.cs`, `L10nUi.cs`, `L10nCore.cs`).
- `Android/app/java/ru/firedrop/app/` — Android-приложение; `L10n.java` + фрагменты `L10nA/S/R/Q.java` — таблицы строк.
- `Android/build.ps1` (Windows), `Android/fdroid-build.sh` (Linux) — сборка APK.
- `metadata/ru.firedrop.app.yml` — метаданные F-Droid; `Android/fastlane/metadata/` — описания и changelog.
- `verification/` — смоук-тесты обоих приложений.
- `dist/` — готовый выпуск Windows.

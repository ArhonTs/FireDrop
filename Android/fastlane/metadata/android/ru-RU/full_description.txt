FireDrop передаёт файлы и целые папки напрямую между устройствами одной локальной Wi-Fi сети: с телефона на компьютер, с компьютера на телефон и с телефона на телефон. Без интернета, облака и регистрации — передача не выходит за пределы комнаты.

Возможности:
• Папки отправляются целиком, структура вложенных каталогов сохраняется.
• Скорость ограничена только Wi-Fi сетью (десятки МБ/с — реальный ориентир).
• Подключение по QR-коду или шестизначному коду с ограничением попыток.
• Принятые файлы не перезаписываются: повторяющиеся получают имена (1), (2)…
• Приём идёт в foreground-сервисе с постоянным уведомлением.

Трафик — только обычный HTTP внутри локальной сети: приложение подключается к явно указанным адресам вида IP:порт, которые видит пользователь; наружу ничего не отправляется.
